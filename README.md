# BinPack Microservice (ASP.NET Core)

A simple .NET 8 microservice for solving 2D bin packing problems using a binary tree algorithm. Built to support a frontend visualizer (flutter).

---

## Features

- Accepts a list of 2D boxes via JSON
- Packs boxes into a fixed-size container
- Returns their `(x, y)` positions within the bin
- CI/CD pipeline using Azure DevOps
- Hosted on Azure App Service
